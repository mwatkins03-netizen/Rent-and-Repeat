# Rent & Repeat

An Oxford closet-share prototype: browse outfit rentals by event, see only what is free for your dates, request a booking, and keep the owner's closet, bookings and numbers in one place. Everything stays in the browser (localStorage); nothing is sent anywhere.

Idea and design direction by Sienna Molsbee 2030 (WRIT 3810), a Grove Lab: Student Studio project with Marc Watkins. Coded with Anthropic's Claude. Unofficial; not affiliated with the University of Mississippi.

Single file: open `index.html`, or deploy the folder to GitHub Pages.
